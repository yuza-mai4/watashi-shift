わたしのシフト v16（ホーム画面追加対応版）

【v16の変更点】
・PWA用のmanifest.webmanifestを追加しました。
・ホーム画面アイコン（192px／512px）を追加しました。
・Service Workerを追加し、対応ブラウザではアプリ画面をキャッシュしてオフライン利用しやすくしました。
・AndroidのChromeでインストール可能な状態になると、画面上部に「ホーム画面に追加」ボタンが表示されます。
・従来の勤務登録、シフトパターン、月間集計、時給履歴、給与設定、バックアップ・復元機能は維持しています。
・v15以前のJSONバックアップは同じ形式のため、アプリの「バックアップから復元」から読み込めます。

【重要：ホーム画面に追加する方法】
このZIPを解凍してindex.htmlを直接開く方法（file://）では、PWAとしてインストールできません。
1. このshift12フォルダーの中身を、HTTPSで公開できる静的Webホスティング先に配置してください。
2. 公開されたHTTPSのindex.htmlをAndroidのGoogle Chromeで開きます。
3. 画面上部に「ホーム画面に追加」ボタンが出たらタップします。出ない場合はChrome右上の︙メニューから「アプリをインストール」または「ホーム画面に追加」を確認してください。

【データについて】
・勤務データはブラウザ内（localStorage）に保存されます。オンラインアカウントに自動同期されません。
・元のfile://版、別のブラウザ、別の公開URLは保存領域が異なる場合があります。新しい公開先で使い始める前に、元のアプリでJSONバックアップを作成し、新しいアプリの「バックアップから復元」で読み込んでください。
・復元すると、復元先にある現在のデータは置き換わります。先に復元先のデータも必要ならバックアップしてください。
・ブラウザのデータ削除やサイトデータの消去で、アプリ内データが消えることがあります。定期的にJSONバックアップを保存してください。
・Service Workerのオフライン動作は、HTTPSで公開された環境で有効になります。

【給与設定について】
v15の初期設定では、2026年10月1日以降の時給が1,130円になっています。これまでの希望と異なる場合は、アプリの「設定」で時給履歴を確認・修正してください。既存バックアップの値は、データを勝手に変更しないため自動では書き換えません。
